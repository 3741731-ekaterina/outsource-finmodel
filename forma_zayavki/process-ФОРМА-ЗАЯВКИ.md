## ТЕКУЩАЯ ПРОБЛЕМА

- Форма на Яндекс.Формах → уведомление приходит на **почту**
- Почту проверяю редко → **заявки теряются**
- Форма визуально не нравится и не отражает бренд
- Ссылка на старую форму стоит во всех статьях Яндекс.Дзен — нужно обновить

## ЗАДАЧА А: Новая форма заявки на Vercel + уведомление в Telegram

### 1. ЧТО ЗАПУСКАЕТ ПРОЦЕСС?
Потенциальный клиент переходит по ссылке из статьи Яндекс.Дзен и заполняет анкету.

---

### 2. ПОШАГОВЫЕ ДЕЙСТВИЯ (целевой процесс)

```
Клиент заполняет форму на Vercel
  → Submit → API Route (serverless функция на Vercel)
    → Данные уходят в Telegram-бот Екатерины
      → Сообщение: «Новая заявка! Имя, телефон, ниша, выручка...»
    → (Опционально) Данные пишутся в Google Sheets
      → Клиенту автоответ на email: «Получили вашу заявку, свяжемся в течение...»
```

---

### 5. ГДЕ МОЖНО СЛОМАТЬСЯ?

| Проблема | Риск |
|----------|------|
| Telegram-бот заблокирован или token протух | Уведомления не приходят |
| Vercel serverless функция упала | Заявка не отправилась, клиент не знает |
| Google Sheets API лимит | Редко, но бывает при высоком трафике |
| Клиент не указал правильный email | Автоответ не дошёл |

**Защита:** на форме показывать страницу «Спасибо» только после подтверждения записи + дублировать в Sheets.

## ЗАДАЧА Б: Замена ссылки в статьях Яндекс.Дзен

### Текущая ситуация
Во всех (или многих) статьях стоит ссылка на старую форму Яндекс.Форм.
Нужно заменить на новую ссылку (Vercel).

---

### Реальные варианты

#### Вариант 1 — Вручную (реалистично при до 20 статей)
Открыть каждую статью в редакторе Дзен → найти ссылку → заменить.
Время: ~3–5 минут на статью.

#### Вариант 2 — Через Яндекс.Дзен API ⚠️
Яндекс.Дзен **не предоставляет публичный API** для редактирования статей.
Автоматическая замена через скрипт **технически невозможна** без обхода через браузерную автоматизацию.

#### Вариант 3 — Браузерная автоматизация (Playwright/Puppeteer) 🟡
Скрипт открывает браузер, логинится в Дзен, обходит список статей, находит ссылку, заменяет.
**Технически возможно**, но:
- Требует разработки (2–4 часа работы)
- Яндекс может посчитать активность подозрительной
- Если статей менее 30 — проще сделать вручную

#### Вариант 4 — Редирект-страница (самое элегантное решение) ✅
Создать на Vercel страницу-редиректор: `yakkhontova.vercel.app/consult`
Эта страница **сразу перенаправляет** на актуальную форму.

**Преимущество:** ссылку в статьях Дзен меняешь **один раз** на редиректор.
В дальнейшем, если форма изменится — меняешь только редирект на Vercel, статьи не трогаешь никогда.

---

### Рекомендация по Задаче Б

1. Сначала создать форму на Vercel с постоянной ссылкой
2. Один раз обновить ссылки в статьях Дзен вручную (или через редирект)
3. Больше никогда не трогать статьи при смене формы
