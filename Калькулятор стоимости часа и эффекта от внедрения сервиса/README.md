# Калькулятор стоимости часа собственника

Веб-калькулятор по мотивам Google Таблицы `Копия Калькулятор стоимости часа`.

Он считает:

- стоимость часа собственника;
- стоимость ручного ведения отчетов;
- экономию времени после внедрения сервиса учета;
- потенциальную экономию на расходах;
- накопительный эффект за 12 месяцев.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
npx serve .
```

## Публикация

Проект статический и готов к деплою на Vercel без сборки.

## Контрольные значения

При исходных данных:

- дивиденды: `500 000`;
- рабочие часы: `160`;
- часы на отчеты: `20`;
- стоимость сервиса: `200`;
- оборот: `8 000 000`;
- сокращение расходов: `2%`.

Ожидаемые результаты:

- стоимость часа: `3 125 ₽`;
- учет сейчас в месяц: `62 500 ₽`;
- экономия на времени в месяц: `62 300 ₽`;
- экономия на времени в год: `747 600 ₽`;
- экономия на расходах в месяц: `160 000 ₽`;
- экономия на расходах в год: `1 920 000 ₽`.
